# NOCTURNE · Unreal experiment

Настоящая Unreal-сцена с геометрией букв: 103 `Text3DActor`, экструзия,
четырёхсегментные фаски, металлические боковые поверхности, три прямоугольных
источника света и кинокамера. Композиция содержит тонкую панель управления,
код, переменные справа, stdin/stdout под ними и консоль под кодом.

Это отдельный визуальный эксперимент. Кнопки и панели здесь являются объектами
сцены; редактирование кода, перетаскивание разделителей и LLDB не подключены.
Интерактивные варианты находятся в основном браузерном прототипе.

## Что уже проверено

- Установлен локальный Unreal **5.8.2**, Apple M1 Pro.
- Python commandlet реально выполнен, создание сцены завершилось с **0 errors**.
- Карта сохранена: `Content/Nocturne/CinematicIDE.umap`.
- Материалы сохранены: `Content/Nocturne/Materials/`.
- Отчёт движка: `build-report.json`; подробный локальный журнал: `build.log`.
- GPU commandlet завершился с 0 errors и записал PNG, однако проверка
  изображения обнаружила полностью чёрный кадр: RGB min=max=0. Поэтому
  `rendered` установлен в `false`: готового визуального рендера Unreal нет.
  Неудачный диагностический кадр переименован в `failed-offscreen-black.png`.
  Дополнительная попытка с обновлением editor-сцены потребовала повторной
  компиляции материалов и была остановлена в пределах эксперимента.
- Цвета лицевой поверхности взяты из `../src/xcode-palette.json`, `dark.raw`,
  извлечённого из установленной стандартной темы Xcode. Значения sRGB переведены
  в линейное пространство материалов Unreal. Тонмаппинг, свет и фаски могут
  менять итоговые пиксели; исходные значения темы не менялись.

## Открыть сцену

Открыть `Nocturne.uproject` в Unreal 5.8. Карта назначена стартовой. Для нужного
ракурса выбрать `NOCTURNE_Camera` в Outliner и включить Pilot. Шрифт —
встроенный моноширинный Droid Sans Mono; дополнительная установка не нужна.

Пересоздать сцену без открытия интерфейса редактора:

```sh
./generate.command
```

Генератор создаёт только ресурсы `/Game/Nocturne`. Повторный запуск заменяет
объекты сцены с префиксом `NOCTURNE_`; пользовательские объекты не удаляет.

## Экспериментальный offscreen-рендер

```sh
./render.command
```

Команда использует Metal и SceneCapture2D с целевым размером 2560×1600,
сохраняет `nocturne-unreal.png`. Сохранённый `failed-offscreen-black.png` —
неудачный диагностический кадр, не превью дизайна. Первая компиляция шейдеров
заняла около 16 минут вместе с материалами.
Вариант `render_ticked.py` ждёт обновлений редактора; его результат ещё не проверен.
Смотрите актуальный результат в `build-report.json`: наличие сохранённой карты
само по себе не подтверждает успешный PNG-рендер. 8K-рендер пока не проверялся.

Unreal может записывать собственный кэш в стандартные каталоги пользователя;
дополнительные плагины или движки не скачивались.

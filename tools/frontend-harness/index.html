stdout содержит только байты, которые программа уже сбросила в pipe. При запуске через pipe обычный std::cout << "...\n" может оставаться в буфере до flush или завершения процесса. Runtime-поле показывает этот буфер только когда backend подтвердил его чтение; статический прогноз не выдаётся за факт.
